# SQUADUP — поиск тиммейтов для кооперативных и соревновательных игр

Веб-приложение, которое помогает находить напарников в **любые игры с кооперативом или соревновательным режимом**: CS2, Dota 2, VALORANT, Helldivers 2, ARC Raiders, Battlefield 6, Minecraft, WoW и ещё 33 тайтла в каталоге.

---

## Что уже работает

| Раздел | Возможности |
|---|---|
| **«Ищу сейчас»** | Живая лента: жмёшь «Я готов играть» — появляешься сверху у всех, кто ищет компанию (окно 90 минут, лента уважает фильтры игры и региона). Прямо из ленты — «Позвать» или «Профиль». |
| **Поиск игроков** | Фильтры: игра (40 тайтлов), режим (кооп / соревновательный), платформа (PC, PS, Xbox), регион (8), язык, уровень, настрой, «онлайн сейчас», «с микрофоном». Поиск по нику и описанию, 4 варианта сортировки. |
| **Карточка игрока** | Аватар с цветом по нику, индикатор онлайна, возраст, регион, ранг и роль в каждой игре, часы, рейтинг и отзывы тиммейтов, расписание игры, контакт для связи. |
| **Отзывы** | После катки можно поставить оценку 1–5 и написать отзыв — рейтинг игрока пересчитывается автоматически. Свой отзыв можно изменить; себе отзыв оставить нельзя. |
| **Контакты** | Поле Discord/Telegram в анкете, кнопка «копировать» в профиле и приглашении; контакт автоматически подставляется в черновик сообщения. |
| **Приглашение** | Кнопка «Позвать» готовый черновик сообщения игрок получает его в чате. |
| **Чаты** | **Реальные диалоги между аккаунтами**: сообщение, отправленное с одного телефона, приходит на другое за секунды (опрос каждые 4 с + push при закрытом приложении). Непрочитанные считаются у обоих участников, счётчик в шапке. Демо-анкеты отвечают заготовленными фразами и помечены меткой «демо», живые игроки — меткой «игрок». |
| **Модерация** | Жалоба на игрока (6 причин) и блокировка в один клик из карточки или из чата. Заблокированные не видят друг друга: анкета исчезает из поиска, диалог — из списка чатов. Три жалобы автоматически скрывают анкету до проверки; админ-API `/api/admin/reports` с ключом `ADMIN_KEY` умеет отклонить, скрыть и восстановить. Список блокировок с разблокировкой — в «Моей анкете», защита от накрутки жалоб одним человеком. |
| **Сквады** | 14 составов, набирающих игроков: состав «3/5», нужные роли, требования по рангу и микрофону. Подача заявки в один клик + создание своего сквада. |
| **Моя анкета** | Ник, возраст, регион, уровень, настрой, до 4 игр с рангом и ролью, платформы, языки, расписание, описание. После сохранения анкета появляется в общем поиске. |
| **Вход и пароль** | Аккаунт под паролем: на сервере лежит только необратимый хеш (PBKDF2-HMAC-SHA256, 120 000 итераций и персональная соль) — сам пароль не хранится и восстановлению не подлежит. Смена пароля в «Моей анкете»: после неё прежние сессии отключаются. Защита от перебора: после 12 неудачных попыток за 10 минут вход по этому нику временно блокируется. Аккаунты, созданные входом через Discord или Steam, задают пароль один раз одноразовым ключом. |
| **Первый запуск** | Сразу после регистрации открывается мастер из трёх шагов: ник и регион, до 4 игр с рангами и ролями, пара слов о себе. Анкета готова за минуту и тут же появляется в поиске. Мастер можно закрыть («Позже») — в поиске останется кнопка «Заполнить анкету». |
| **Сохранность данных** | Резервная копия всей базы одним JSON-файлом и восстановление из неё: `GET /api/admin/backup` и `POST /api/admin/restore` (только с ключом `ADMIN_KEY`). В выгрузке — хеши паролей, а не сами пароли. Пригодится на бесплатном хостинге, где базу может обнулить перезапуск. |
| **Вход через Discord** | OAuth2: привязка Discord к анкете (и отвязка), ник подтягивается из Discord. Включается переменными `DISCORD_CLIENT_ID` / `DISCORD_CLIENT_SECRET`. |
| **Привязка Steam** | Официальный вход Steam через OpenID 2.0: **пароль от Steam вводится только на steamcommunity.com** — мы его не получаем и не храним, доступ к аккаунту не запрашивается. Ник и аватар подтягиваются из публичного профиля (ключ Steam Web API не нужен). Игрок сам решает, показывать ли ник и ссылку другим; отвязка в один клик; один Steam — одна анкета. Ответ Steam проверяется отдельным запросом к его серверам, поэтому подделать привязку нельзя. |
| **Уведомления** | Настоящий Web Push (VAPID + aes128gcm): сообщения, приглашения и заявки в сквады приходят при **закрытом** приложении. Счётчик на иконке приложения (Badge API), клик открывает нужный экран. |
| **Фоновая работа** | Service worker: Periodic Background Sync (проверка непрочитанных), Background Sync с очередью — сообщения, написанные без сети, уходят сами. |
| **Приватность** | Политика конфиденциальности (`/privacy.html`), экспорт своих данных одним файлом, удаление аккаунта со всеми данными — требования Google Play и App Store. |
| **PWA** | Устанавливается на телефон иконкой (Android/Chrome/Edge + iPhone/Safari), офлайн-оболочка, ярлыки «Ищу сейчас» / «Сквады» / «Чаты», скриншоты для магазинов в манифесте. |
| **Ассеты для магазинов** | Скриншоты 1080×1920 (×6), планшет, десктоп, feature graphic 1024×500, иконки 512/maskable, `assetlinks.json` для Android TWA, `twa-manifest.json`, план публикации — [STORE.md](STORE.md). |

Демо-база содержит **88 анкет игроков** и **14 сквадов**, чтобы приложение выглядело и работало «как живое».

## Технологии

- **Бэкенд:**Python 3 и стандартная библиотека (`http.server` + `sqlite3`). Единственная необязательная зависимость — `cryptography` (для push-уведомлений); без неё приложение работает, но кнопка уведомлений скрыта.
- **Фронтенд:** один файл `static/index.html` — HTML + CSS + чистый JS, без библиотек и внешних CDN (работает даже без интернета).
- **Данные:**SQLite-файл `data.db` создаётся автоматически при первом запуске вместе с демо-данными.

```
squadup/
|-- server.py # сервер + REST API + OAuth Discord + push + генерация демо-данных
|-- webpush.py # Web Push: VAPID-подпись и шифрование aes128gcm (RFC 8291/8292)
|-- requirements.txt # необязательная зависимость cryptography (уведомления)
|-- data.db # база (создаётся автоматически; путь меняется через DB_PATH)
|-- static/
```

## Запуск

```bash
cd squadup
python3 server.py
# http://localhost:8000
```

Порт можно сменить: `PORT=9000 python3 server.py`, путь к базе — `DB_PATH=/data/squadup.db python3 server.py`.

### Запуск в Docker

```bash
docker compose up --build # http://localhost:8000
```

### Выложить в интернет (публичная ссылка + том для базы)

> **Самый простой путь — [QUICKSTART.md](QUICKSTART.md)**: пошаговая инструкция «GitHub, затем Render»
> без опыта и без карты, ~10 минут. Результат — постоянная ссылка вида `https://squadup-xxxx.onrender.com`.

В репозитории лежат готовые `Dockerfile`, `render.yaml`, `railway.toml`, `docker-compose.yml`, а пошаговая инструкция для Railway, Render, VPS и Fly.io — в **[DEPLOY.md](DEPLOY.md)**. Health-check: `GET /healthz`.

### Привязка Steam (работает сразу, настраивать нечего)

В «Моей анкете» есть кнопка **«Привязать Steam»**. Она уводит пользователя на официальную страницу
Steam (OpenID 2.0), где он подтверждает вход — **пароль остаётся на стороне Steam**, наш сервер его
не запрашивает и не хранит. После возврата мы получаем подтверждённый SteamID и, если профиль открыт,
ник с аватаром.

- Ключи Steam Web API не нужны.
- Один Steam-аккаунт привязывается только к одной анкете.
- Игрок сам управляет показом: ник и ссылку на профиль видят другие, пока он не нажал «Скрыть из анкеты».
- «Отвязать» удаляет SteamID, ник и аватар из анкеты; удаление аккаунта убирает их полностью.
- Если Steam не отдал профиль (закрытый профиль или лимит запросов), привязка всё равно сохраняется, а в профиле появляется кнопка «Обновить данные».

Для автотестов без реального Steam есть переменные `STEAM_OPENID_ENDPOINT` и `STEAM_PROFILE_XML`,
переопределяющие адреса Steam.

### Вход через Discord (необязательно)

```bash
DISCORD_CLIENT_ID=... DISCORD_CLIENT_SECRET=... python3 server.py
```

Подробная инструкция по получению ключей и настройке Redirect URI — в [DEPLOY.md](DEPLOY.md#вход-через-discord-рекомендуется-для-публичного-запуска). Без этих переменных вход по нику и паролю работает как обычно, а кнопка Discord скрыта.

### Установка на компьютер (Windows / macOS / Linux)

- **Windows:** `launcher\start.bat` запускает сервер и открывает окно приложения; `launcher\install-windows-shortcut.ps1` создаёт ярлык с иконкой на рабочем столе и в «Пуск».
- **macOS / Linux:** `./launcher/start.sh` (остановка — `./launcher/stop.sh`); для меню приложений Linux — `launcher/squadup.desktop`.
- **PWA в браузере:** в Chrome/Edge нажми «Установить» в адресной строке — приложение встанет как обычная программа со своей иконкой.

### Установка на телефон

Открой приложение по **HTTPS-адресу** в браузере телефона. Android/Chrome: меню браузера, пункт «Установить приложение». iPhone/Safari: «Поделиться», затем «На экран „Домой“». Пункт «Установить приложение» есть и в меню профиля — он подскажет шаги для твоего устройства. С http-адреса по локальной сети установка недоступна (браузеры требуют HTTPS) — для постоянного варианта выложи приложение по инструкции в [DEPLOY.md](DEPLOY.md).

### Чтобы сбросить демо-базу

```bash
rm data.db && python3 server.py
```

## Как пользоваться

1. Придумай ник и пароль (не короче 6 символов) — аккаунт создаётся сразу, и мастер за три шага соберёт анкету: ник, регион, игры с рангами, пара слов о себе. Вход дальше — по этому же нику и паролю.
2. Заполни **«Мою анкету»** (включая Discord/Telegram) — после сохранения тебя начнут видеть другие игроки.
3. Нажми **«Я готов играть»** — ты появишься в живой ленте «Ищу сейчас», а игроки смогут позвать тебя в один клик.
4. Во вкладке **Поиск** настрой фильтры: например `Helldivers 2 + Кооп + PC + микрофон`, нажми **«Позвать»** — откроется черновик сообщения с твоим контактом.
5. После совместной катки открой профиль игрока и оставь **отзыв** — рейтинг обновится.
6. Во вкладке **Сквады** подай заявку в состав или создай свой.

## Уведомления и фоновая работа

Уведомления включаются в приложении: в меню профиля: **Уведомления**, затем «Включить уведомления».
Проверить фоновую доставку можно кнопкой **«Через 30 сек»** — закрой приложение, уведомление всё равно придёт.

| Событие | Когда приходит |
|---|---|
| Сообщение в чате | когда собеседник отвечает (в демо — после автоответа) |
| Приглашение | когда игрок зовёт тебя в группу |
| Заявка в сквад | когда кто-то подал заявку в твой сквад |
| Напоминание | раз в ~3 часа, если есть непрочитанные (Chrome, установленное приложение) |

Сервер генерирует VAPID-ключи сам при первом запуске (и хранит в базе) либо берёт из переменных
`VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT`.

## REST API (кратко)

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/games` | каталог игр, режимов, платформ, регионов |
| GET | `/api/stats` | счётчики для главной |
| POST | `/api/login` | вход по нику и паролю: новый ник создаёт аккаунт, существующий проверяет пароль и возвращает токен |
| POST | `/api/password/setup` | задать пароль аккаунту, созданному входом через Discord или Steam (одноразовый ключ приходит в ответе `/api/login`) |
| GET/POST | `/api/me/has-password` · `/api/me/password` | есть ли у аккаунта пароль; смена пароля (прежние сессии после этого не работают) |
| GET | `/api/me` | профиль, анкета, заявки, непрочитанные |
| GET | `/api/players?game=&mode=&platform=&region=&lang=&skill=&vibe=&mic=&online=&q=&sort=` | поиск тиммейтов |
| GET | `/api/players/{id}` | профиль игрока: отзывы, мой отзыв, контакт, статус «ищу сейчас» |
| POST | `/api/players/{id}/review` | поставить/изменить отзыв (1–5, текст) — пересчитывает рейтинг |
| GET | `/api/looking?game=&region=` | лента «ищу сейчас» (окно 90 мин) |
| POST | `/api/looking` | включить/выключить «Я готов играть» |
| PUT | `/api/listing` | создать/обновить свою анкету (включая Discord/Telegram) |
| POST | `/api/invite` | приглашение игроку: создаёт диалог, в котором видят друг друга оба |
| GET | `/api/chats` | мои диалоги (оба направления), непрочитанные, последнее сообщение |
| GET/POST | `/api/chats/{id}/messages?after=` | сообщения диалога; отправка шлёт собеседнику push |
| POST | `/api/chats/{id}/read` · `/simulate-reply` | отметка о прочтении; демо-ответ (для живых игроков выключен) |
| POST | `/api/report` | жалоба на игрока/сквад/сообщение (`reason`: spam, insult, fake, fraud, adult, other) |
| POST | `/api/block` · `/api/unblock` · GET `/api/blocks` | блокировка игрока (по анкете или чату), разблокировка, список блокировок |
| GET | `/api/admin/reports?key=` · POST `/api/admin/report-resolve` | модерация: список жалоб и решения `dismiss` / `hide` / `restore` (включается переменной `ADMIN_KEY`) |
| GET/POST | `/api/admin/backup` · `/api/admin/restore` | резервная копия базы и восстановление из неё (ключ `ADMIN_KEY` в заголовке `X-Admin-Key` или в `key=`) |
| GET | `/api/config` | настройки сервера (Discord, уведомления) |
| GET | `/api/push/state` · POST `/api/push/subscribe` · `/unsubscribe` · `/test` · `/schedule` | подписка и проверка уведомлений |
| GET | `/api/me/export` | скачать все свои данные (JSON-файл) |
| DELETE | `/api/me` | удалить аккаунт и все данные |
| GET | `/privacy.html` · `/.well-known/assetlinks.json` | политика конфиденциальности и проверка домена для Android |
| GET | `/api/auth/discord/login` · `/callback` | OAuth2-вход/привязка Discord |
| POST | `/api/unlink-discord` | отвязать Discord от анкеты |
| GET | `/healthz` | health-check для платформ |
| GET | `/api/chats` · GET/POST `/api/chats/{id}/messages` | чаты и сообщения |
| GET/POST | `/api/squads` · POST `/api/squads/{id}/apply` | сквады и заявки |

Авторизация — заголовок `X-Token`.

## Идеи для развития

- Восстановление пароля по e-mail и подтверждение почты (сейчас пароль восстановить нельзя — его видит только владелец).
- Загрузка скриншотов профиля из Steam/PSN.
- Скрейпинг статистики ранга через публичные API игр (Steam, Riot, Tracker.gg).
- Голосовые комнаты (WebRTC) вместо сторонних Discord-серверов.
- Матчмейкинг-лента «ищу 2 из 5 прямо сейчас» с автосбором группы.
- Антитоксик-рейтинг и автопроверка жалоб (сейчас спорные анкеты разбирает модератор).
