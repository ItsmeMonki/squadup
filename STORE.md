## Шаг 1. Свой домен и постоянный хостинг (обязательный шаг)

Установка на телефон, push и TWA работают только по HTTPS с постоянным адресом.

1. Зарегистрируй домен (например, `squadup.app`) — около 10–15 € в год.
2. Разверни приложение по `DEPLOY.md` (Railway/Render/VPS), получи `https://squadup.app`.
3. Проверь: `https://squadup.app/healthz` → `{"ok": true, ...}`, в браузере телефона сайт предлагает «Установить приложение».
4. Впиши домен в `privacy.html` (контактную почту) и в `twa-manifest.json` (вместо `ТВОЙ-ДОМЕН.example.com`).

## Шаг 2. Google Play (Android) — путь через TWA

TWA (Trusted Web Activity) — официальный способ Google упаковать PWA в настоящее Android-приложение: оно попадает в Play, живёт в фоне, показывает уведомления.

```bash
# на своём компьютере, нужны Node.js 18+ и JDK 17
npm i -g @bubblewrap/cli

# в корне проекта
bubblewrap init --manifest https://squadup.app/manifest.webmanifest
#   → bubblewrap спросит домен; можно взять готовый twa-manifest.json как основу:
#     "Application name": SQUADUP — поиск тиммейтов, package: app.squadup.twa

bubblewrap build          # создаст app-release-bundle.aab и app-release-signed.apk
bubblewrap fingerprint    # покажет SHA-256 отпечаток ключа → вставь его в assetlinks
```

5. Вставь отпечаток в переменную окружения сервера на хостинге:
   `TWA_SHA256_FINGERPRINTS=AA:BB:CC:...` (через запятую, если ключей несколько: у Play есть свой ключ подписи).
6. Проверь: `https://squadup.app/.well-known/assetlinks.json` — там должен быть твой отпечаток.
7. Создай аккаунт разработчика Google Play (разовый платёж **25 $**, https://play.google.com/console).
8. Заполни карточку приложения: название, описание (ниже готовый текст), иконка 512×512, feature graphic, 6 скриншотов телефона — всё это уже есть в `static/`.
9. Заполни «Безопасность данных» (Data safety): укажи, что собираются ник, возраст, контент сообщений — по нашей `privacy.html`. Иначе отклонят.
10. Загрузи `app-release-bundle.aab` во внутреннее тестирование, проверь на своём телефоне, затем — в продакшн.

**Важно про новые аккаунты Play:** для личных аккаунтов, созданных после 13.11.2023, перед публикацией требуется закрытое тестирование с **не менее 12 тестировщиками на протяжении 14 дней**. Это правило Google, его нельзя обойти.

## Шаг 3. App Store (iOS)

App Store **не принимает** простые обёртки сайтов — Apple отклоняет приложения, у которых мало «нативной» ценности (пункт 4.2 гайдлайнов). Реалистичные варианты:

**Вариант A — быстрый (рекомендую для старта):**
iOS-пользователи устанавливают приложение как PWA: Safari → «Поделиться» → «На экран Домой».
С iOS 16.4+ у такой иконки работают push-уведомления и бейджи. В магазин не попадаем, но функционально приложение на телефоне есть.

**Вариант B — нативное приложение (если нужно именно в App Store):**
Нужен слой нативного кода поверх того же бэкенда:

- **React Native / Expo** — самый быстрый путь: экраны на JS, push через APNs + FCM.
- **SwiftUI** — максимальное качество, но дольше.
- **Capacitor** — обёртка вокруг веб-версии плюс нативные плагины (уведомления, биометрия), приложение почти «нативное» для модерации, если добавить пару нативных экранов.

Минимально придётся:
1. Завести Apple Developer Program (**99 $ в год**).
2. Собрать приложение в Xcode, подключить APNs для уведомлений (у нас уже есть бэкенд-логика VAPID — для APNs понадобится отдельный модуль `apns.py`: JWT с ключом `.p8` вместо VAPID).
3. Пройти ревью (1–3 итерации, обычно требуют доработок по 4.2).
4. Заполнить Privacy Nutrition Labels — по нашей `privacy.html`.

Я могу написать скелет на React Native/Expo или Capacitor и модуль отправки APNs — скажи, какой вариант выберем.

## Шаг 4. Windows и macOS (необязательно)

- **Windows**: PWA ставится в Edge/Chrome и появляется в «Пуск» с уведомлениями и бейджем. Более «нативный» вариант — пакет MSIX через [PWABuilder](https://www.pwabuilder.com) (бесплатно, можно даже в Microsoft Store).
- **macOS**: Chrome/Edge → «Установить SQUADUP» — приложение в Launchpad, уведомления работают.

## Шаг 5. Уведомления и фоновая работа — как оно устроено

| Механизм | Где | Что даёт |
|---|---|---|
| Web Push (VAPID + aes128gcm) | `webpush.py`, `sw.js` | уведомления при закрытом приложении; события: сообщения, приглашения, заявки в сквады |
| Клик по уведомлению | `sw.js` | открывает приложение на нужном экране (`/api/...` → `/?view=chats`) |
| Badge API | `sw.js` | счётчик на иконке приложения |
| Periodic Background Sync | `sw.js` | раз в 3 часа проверяет непрочитанные (Chrome, установленное PWA) |
| Background Sync + очередь | `sw.js`, `index.html` | сообщения, написанные без сети, уходят сами |
| Демо-проверка фона | кнопка «⏱ Через 30 сек» в разделе «Уведомления» | показывает, что уведомление приходит при закрытом приложении |

**Честные ограничения фоновой работы в вебе и TWA:**
- приложение не может постоянно висеть в памяти — система его выгружает; но push-сервис будит service worker в момент события (это и есть «фоновая работа» по факту);
- Periodic Background Sync работает в Chrome/Android и только у установленного приложения, интервал определяет браузер;
- iOS: push работают только у приложения, добавленного на экран «Домой», и только с iOS 16.4+;
- если понадобится настоящий демон (например, трекинг в реальном времени с постоянным соединением), это уже нативное приложение — обсуждаем в шаге 3B.

## Тексты для карточки Google Play (можно копировать)

- **Название (30 симв.):** `SQUADUP: поиск тиммейтов`
- **Краткое описание (80 симв.):** `Найди тиммейтов в кооперативных и соревновательных играх за пару минут`
- **Полное описание:**
  `SQUADUP — это поиск тиммейтов для любых игр с кооперативом и соревновательным режимом: CS2, Dota 2, VALORANT, Helldivers 2, ARC Raiders, Battlefield 6, Minecraft и ещё 33 тайтла.
  • Фильтры по игре, режиму, платформе (PC/PS/Xbox), региону, рангу, роли и наличию микрофона
  • Живая лента «Ищу сейчас»: нажми «Я готов играть» — и тебя увидят
  • Анкеты с рангами, ролями, расписанием, рейтингом и отзывами тиммейтов
  • Встроенный чат и приглашения в один клик
  • Сквады, которые набирают игроков: подай заявку или собери состав
  • Уведомления приходят, даже когда приложение закрыто
  Работает на телефоне, планшете и компьютере. Вход за 10 секунд — ник или Discord, пароль не нужен.`
- **Категория:** Игры → Казуальные/Социальные. **Теги:** поиск тиммейтов, LFG, кооператив.
- **Рейтинг контента:** заполни опросник честно — у нас общение пользователей (чат), это влияет на рейтинг.
