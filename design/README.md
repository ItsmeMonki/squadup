# Дизайн SQUADUP: как передать ассеты

Стиль приложения — по референсу **aristidebenoist.com**: чёрный холст, волосяные линии 1px,
моно-лейблы капсом, крупная типографика, постеры в цвете, без градиентов, теней и скруглений.
Эмодзи убраны полностью.

## Флоу приложения

1. **Приёмная** — регистрация одним ником (полный экран, первый экран приложения).
2. **Стена игр** — 40 постеров в цвете, живые цифры под каждым, поиск по названию
   и категории (кооп / соревновательные / жанры).
3. **Экосистема игры** — кадр игры, цифры, игроки именно этой игры, лента «ищу компанию»,
   чаты и сквады в контексте выбранной игры.

## Что нужно от тебя

Присылай файлы **прямо в чат** (перетащи в поле ввода) — заберу и подключу сам.

### 1. Логотип и иконка — `design/brand/`

| Файл | Формат | Куда встанет |
|---|---|---|
| `wordmark.svg` | SVG | шапка приложения вместо текстового «SQUADUP» |
| `logo.svg` | SVG | знак для особых мест |
| `icon-master.png` | PNG 1024×1024, квадрат | все размеры иконок: 192, 512, maskable, apple-touch, favicon, .ico |

### 2. Два шрифта — `design/fonts/`

| Слот | Где применяется | Начертания |
|---|---|---|
| **Заголовочный** | «ВЫБЕРИ ИГРУ», названия игр, ники, крупные цифры | 400 + 700 |
| **Текстовый** | весь остальной текст | 400 + 500 + 700 |

Формат **WOFF2** (TTF/OTF тоже подойдёт — сконвертирую). Моноширинный для подписей
`— 40 ИГР В КАТАЛОГЕ` сейчас системный: если хочешь свой (необязательно),
пришли третьим файлом и назови `Mono-Regular.woff2`.

### 3. Палитра — `design/tokens.json`

Сейчас стоит черновой вариант по твоему направлению: глубокий чёрный `#050505`
и неоновый оранжевый `#ff6a00`. Замени значения на свои — они применятся ко всему
приложению (фон, панели, границы, текст, акцент, свечение, цвета PWA-манифеста).

### 4. Свои постеры игр — необязательно

Файл `design/covers/<id>.(jpg|png|webp)` перекрывает официальную обложку Steam.
Идентификаторы: `cs2`, `valorant`, `dota2`, `lol`, `apex`, `ow2`, `r6`, `cod`,
`marvel_rivals`, `fortnite`, `pubg`, `rl`, `bf6`, `deadlock`, `eafc`, `hd2`,
`arc_raiders`, `tarkov`, `delta`, `drg`, `pd3`, `destiny2`, `warframe`, `division2`,
`lethal`, `phasmo`, `sot`, `bg3`, `mhw`, `minecraft`, `valheim`, `palworld`,
`terraria`, `enshrouded`, `itt`, `rust`, `gta`, `wow`, `ffxiv`, `albion`.
Пропорции 2:3 (например 1200×1800). Полезно для игр без обложки в Steam —
их постеры сейчас типографические: VALORANT, LoL, Fortnite, Tarkov, Minecraft, WoW.

## Что произойдёт, когда пришлёшь файлы

```bash
python3 design/apply_design.py --check   # посмотреть, чего не хватает
python3 design/apply_design.py           # применить всё
```

Скрипт: копирует шрифты и логотип, генерирует все размеры иконок из мастер-файла,
собирает `theme.css` из токенов, подключает его в `index.html`, обновляет цвета
и иконки PWA-манифеста, копирует свои постеры игр.
