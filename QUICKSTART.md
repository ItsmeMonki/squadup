# SQUADUP: публикация за 10 минут (без опыта)

После этих шагов у тебя будет **постоянная ссылка** вида `https://squadup-xxxx.onrender.com`,
которая не умирает никогда. Открываешь её с телефона «Установить приложение» играешь.
Понимает и нажимает всё человек: тебе нужны только аккаунты GitHub и Render (оба бесплатные).

---

## Шаг 1. Загрузить проект на GitHub (5 минут)

GitHub — это бесплатное хранилище кода, из которого хостинг забирает проект.

1. Зарегистрируйся на **github.com** (если ещё нет аккаунта).
2. Нажми зелёную кнопку **New** (или «+» в правом верхнем углу *New repository*).
3. В поле **Repository name** напиши `squadup`. Тип оставь **Public**. Нажми **Create repository**.
4. На открывшейся странице нажми ссылку **uploading an existing file**
 (или *Add file* *Upload files*).
5. Перетащи туда **всё содержимое распакованного архива `squadup-deploy.zip`** —
 именно файлы (`server.py`, папку `static`, `Dockerfile`, `render.yaml` и остальные),
 а не саму папку `squadup`. Папку `static` перетаскивай целиком.
 > Проще всего: распакуй архив, зайди внутрь папки, выдели всё (Ctrl+A) и перетащи.
6. Внизу страницы нажми зелёную кнопку **Commit changes**. Подожди ~20 секунд, пока файлы загрузятся.

Файл `data.db` загружать не нужно — приложение создаст базу само, вместе с демо-анкетами.

## Шаг 2. Подключить Render (5 минут)

Render — хостинг, который возьмёт проект с GitHub и запустит его в интернете.

1. Зайди на **render.com** и нажми **Get Started** и зарегистрируйся через кнопку **GitHub**
 (это даст Render доступ к твоим репозиториям).
2. В панели Render нажми **New +** **Blueprint**.
3. Выбери репозиторий `squadup` нажми **Connect**.
4. Render сам прочитает `render.yaml` и покажет сервис **squadup**. Нажми **Apply**.
5. Жди 3–6 минут: Render соберёт контейнер (`Build` `Deploy`).
 В строке сервиса загорится **Live** — это значит, что приложение работает.

**Твоя ссылка** — сверху страницы сервиса, вид `https://squadup-xxxx.onrender.com`.
Она постоянная: сохрани её в закладки и открой с телефона.

## Шаг 3. Первый заход

1. Открой ссылку на компьютере. Приложение попросит ник — впиши любой.
2. Проверь, что поиск работает: выбери любую игру в фильтре анкеты должны появиться.
3. Открой ссылку **на телефоне**:
 - **Android/Chrome:** меню браузера (три точки), пункт **Установить приложение**;
 - **iPhone/Safari:** «Поделиться» **На экран «Домой»**.
 Появится иконка SQUADUP — приложение работает как обычное, уведомления приходят при закрытом приложении.

## Как разбирать жалобы (модерация)

В панели Render открой сервис вкладка **Environment** скопируй значение переменной
`ADMIN_KEY` (Render создал её автоматически). Это твой пароль модератора.

Список жалоб — вставь ключ вместо `ТВОЙ_КЛЮЧ`:

```
https://твоя-ссылка.onrender.com/api/admin/reports?key=ТВОЙ_КЛЮЧ
```

Отклонить / скрыть анкету / вернуть анкету обратно (номер жалобы — поле `id` из списка):

```bash
curl -X POST https://твоя-ссылка.onrender.com/api/admin/report-resolve \
 -H 'Content-Type: application/json' \
 -d '{"key":"ТВОЙ_КЛЮЧ","report_id":1,"decision":"dismiss"}'
```

Решения: `dismiss` (отклонить), `hide` (скрыть анкету), `restore` (вернуть и обнулить счётчик).
Анкета скрывается автоматически после 3 жалоб от разных людей — до твоего решения.

## Частые вопросы

**Ссылка долго открывается при первом заходе.**На бесплатном тарифе Render сервис засыпает
через 15 минут простоя, а первый запрос будит его (~30–50 секунд). Дальше работает быстро.
Это лечится переходом на тариф Starter (~7 $/мес), но для старта бесплатного достаточно.

**Данные пропали после повторного деплоя.**На бесплатном тарифе база живёт внутри контейнера:
при новом деплое она создаётся заново с демо-данными. Чтобы анкеты, чаты и блокировки
сохранялись навсегда — включи диск: инструкция в комментариях внутри `render.yaml`
(тариф Starter и выше), либо разверни на своём VPS по `DEPLOY.md`.

**Хочу свой домен** (`squadup.ru` вместо `onrender.com`): Render твой сервис 
**Settings** **Custom Domain** впиши домен и следуй подсказкам. Для установки приложения
на Android лучше сразу указать домен в `TWA_*`-переменных (см. `STORE.md`).

**Хочу вход через Discord:**Render **Environment** добавь `DISCORD_CLIENT_ID` и
`DISCORD_CLIENT_SECRET` (как их получить — в `DEPLOY.md`), затем `DISCORD_REDIRECT_URI`
равный `https://твоя-ссылка/api/auth/discord/callback`.

**Railway вместо Render** (тоже бесплатный старт, но засыпает иначе): там всё так же —
New Project Deploy from GitHub repo выбрать `squadup`. Конфиг `railway.toml` уже в проекте,
но переменную `ADMIN_KEY` задай вручную: Variables New Variable. Том для базы —
Volumes Add Volume, mount path `/data`, и переменная `DB_PATH=/data/squadup.db`.

**Что-то не работает.**Проверь адреса (замени на свою ссылку):

```bash
curl https://твоя-ссылка.onrender.com/healthz # {"ok": true, ...}
curl https://твоя-ссылка.onrender.com/api/config # версия, уведомления, Discord
curl https://твоя-ссылка.onrender.com/api/stats # анкеты, сквады, игры
```

Если `/healthz` отвечает — приложение живо, проблема в чём-то другом: смотри
Render **Logs** (там видно все запросы и ошибки) и пришли мне строку оттуда.
